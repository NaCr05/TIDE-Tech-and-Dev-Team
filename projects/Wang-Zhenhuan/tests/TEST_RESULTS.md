# TIDE Agent 验收测试结果

> 测试日期：2026-07-23
>
> 测试方式：运行 `node tests/run_acceptance_tests.mjs`，直接调用正在运行的 Agent `/evaluate` 接口。
> 当前模式：`mock`

## 测试结论

六类验收场景均成功执行，接口输出均包含完整性、正确性、主要问题、修改建议、分数、等级、Provider、尝试次数和原始输出。

这里的“通过”表示系统行为符合当前实现的预期和文档描述，不代表 Agent 对答案的教学判断一定正确。误判与能力边界被作为正式测试结果保留。

| 场景 | 观察结果 | 结论 |
|---|---|---|
| 正常完整答案 | 95 / A / correct | 能识别包含 `prev/current/next/O(n)/O(1)` 的完整链表反转答案 |
| 部分正确答案 | 76 / C / mostly_correct | 能指出临时指针与空间复杂度缺失 |
| 明显错误答案 | 20 / F / incorrect | 能识别“排序节点值”不等于反转链表 |
| 不完整或模糊答案 | 55 / F / uncertain | 信息不足时给出不确定结论 |
| Agent 误判记录 | 55 / F / uncertain | 中文语义正确但缺少特定英文关键词时会被低估 |
| 代码执行能力边界 | 95 / A / correct | 即使伪代码不可执行，只要命中关键词仍可能高分 |

## 已确认的能力边界

1. Mock 模式是确定性关键词规则，不是通用语义模型。
2. 当前不会编译或运行学生代码，也没有隐藏测试用例。
3. 当前不能可靠评估任意数据结构题；规则主要围绕单链表反转样例。
4. 同义表达、纯中文表达可能因未命中特定关键词而被误判。
5. 包含正确关键词的错误代码可能获得高分。
6. 因此 AI 结果只能辅助教师，必须保留确认、修改和重新评估流程。

## 可复现实验

在项目根目录、Agent 容器健康的前提下运行：

```powershell
node .\tests\run_acceptance_tests.mjs
```

预期输出：

```text
Acceptance cases: 6/6 matched documented behavior.
```

如需测试真实模型，在 `.env` 中配置 API Key 并将 `AGENT_MODE` 改为 `live` 后重建 Agent。真实模型输出可能变化，应记录实际结果，不应沿用本文件中的 Mock 分数。
